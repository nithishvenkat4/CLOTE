
# CLOTE
### Self-Hosted File Management System with Version Control

A privacy-first file management platform where your laptop 
acts as a private cloud server — with full version history, 
multi-client access, and zero third-party dependency.

## Team
- Person A — Server & Backend
- Person B — Client & Networking

## Tech Stack
- Backend  : Python (FastAPI) + SQLite
- Frontend : React
- Auth     : JWT + bcrypt
- Network  : TLS 1.3 + Tailscale VPN

## Structure
/server   → Backend API server
/client   → Frontend client
/docs     → API contract and design decisions
